# H3 MASQUE boundary and standards review

Frozen source: `eb2c3fd04fbe76d05eae38db61ba9fe825e15a0c`. This is a manual source review, with no runtime or Cargo execution. Existing reports are preserved.

## Confirmed finding

**HB1 (P2): Own and cancel every accepted H3 MASQUE connection.** spawn_on detaches serve_connection tasks. Drop aborts only the accept task. The close receiver is first polled in the accepted relay loop, after TLS, H3 bootstrap, first request and rejected/challenged response waits. Retained QUIC connection references keep the endpoint driver alive; EndpointRef Drop only wakes it.

MasqueProxy documents abort on drop and close_connections closes every open outer connection. A TLS-authenticated peer held alive without first CONNECT or after receiving rejection must observe closure and allow the old listening UDP address to be rebound, while its endpoint/runtime remains alive.

Resolved Quinn endpoint source (293–416, 705–737) distinguishes explicit Endpoint.close from dropping EndpointRef: the driver exits only when both user references and active connections are gone. ConnectionRef Drop (929–971) closes only after the last retained connection/stream reference. The detached H3 task retains those references during first-request and rejection waits. The current outer-close integration caller closes only an already relaying connection after a partial body, then reopens and requires a real second body; it does not cover earlier stages. This is a fixture lifetime defect, not a production-client defect.

Root assigned a separate isolated baseline-control and remedy lane. No tested claim is made here.

## Qualified limits and dispositions

- Ignored relay send/receive failures lose fixture error causes, but selected successful tests require actual response bodies, paths, capsule observations and typed rejection errors. No additional false-green absence finding established merely from ignored I/O.
- H3 target parser accepts literal IPs and does not constrain loopback or consume all path segments. Relay socket is IPv4; selected positive targets are IPv4 loopback. IPv6 negative pin cases fail before connection. No general IPv6 MASQUE fixture claim.
- Capsule accumulation and rejection close-drain have no size cap. Controlled callers, bounded outer test deadlines and owner cancellation limit scope; no arbitrary-input parser approval.
- Varint encoder emits at most four bytes. Selected stream identifiers and packet lengths fit those widths; generic 62-bit encode capability is not established.
- connect_udp.rs Origin::serve also detaches connection and response children; its /stall responder waits forever. This is a supporting trace outside owned full source and needs separate bounded ownership review/assignment.
- masque.rs exceeds the rough file-size review prompt and combines H3 datagrams with H1/H2 stream capsules. A domain split is reasonable after ownership repair; no crate split or speculative framework is needed. Inline current controls are below 300 lines.
- http3_upgrade finish awaits typed task results, closes endpoints and joins cancelled children. Selected source confirms error propagation, without fresh runtime proof.
