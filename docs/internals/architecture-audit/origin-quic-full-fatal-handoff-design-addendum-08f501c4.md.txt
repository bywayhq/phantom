fatal before returning its StreamError wrapper. That includes request

state. The shared OnceLock never clears. Public accept first polls the
shared fatal, closes with its original code and returns its driver view
before request/control work. Immediate Drop otherwise sends H3_NO_ERROR.

bounded public accept for every actual ConnectionError. Ordinary Err is
confirmation of the same shared first cause, rather than an extra failure.
Return the original unmatched error unchanged. Retain actual Elapsed or
unexpected Some/None as an additional handoff cause, with finite ownership
of a returned resolver. Keep explicit setup/accept/resolution matches,
existing timeouts, graceful None and expected peer/idle observations.

can have a narrow incoming policy. The new two literal controls must be
measured before repair. Critical-stream errors can also originate in local
backend writes; setup settings can be local configuration; internal errors
can be local encoder faults. Preserve those original ambiguous causes.
HeaderTooBig must remain original because the same resolution call can
return it from outgoing 431 response encoding. Do not classify by broad
Local/Remote/Undefined labels or use an invented shared-state API.
