select at 240–243 and second acquisition select at 267–270 are unbiased.
Tokio 1.53.1 selects a random starting branch. If shutdown and the actual
accept/TLS future are both ready, shutdown can be selected first. The first
branch returns Ok(None), or the second branch takes Ok(None) and collects only
the first child. The ready original acquisition error is discarded when its
future is dropped. A caller failure then survives without its ready acquisition
cause. This violates the concrete caller-plus-original-cleanup contract; it is
not merely missing exhaustive race coverage. Poll the actual acquisition first
and retain its ready outcome before treating shutdown as cancellation. Preserve
finite shutdown of a genuinely Pending acquisition.
