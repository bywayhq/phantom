SystemTime expiry assertions are finite local observations, not clock-change resilience.

`alt_svc_pinned.rs`: Pinned IP controls retain logical certificate origin and observed authority while changing only dial target. CONNECT-UDP route tests use distinct proxy/origin trust and observed target, and same-origin redirect keeps the pin. Typed preflight controls observe zero proxy connections. Cross-origin negative relies on reserved DNS name behavior; the test does not capture ClientHello SNI directly.

`alt_svc_race.rs`: Actual protocol/body/authority/SNI and nonzero alternative POST observations support winner selection before dispatch. Streaming poll counts, finite datagram stability windows, exact setup budget and caller budget controls are meaningful but not universal quietness proofs. Admission cancellation awaits a cancelled task and later successful exact H3 exchange. Four fixture findings require remediation; no production cause is promoted from these tests.

`http3_upgrade.rs`: Real literal bodies, authorities, TLS names, ordered caller fields and Alt-Used behavior are checked. Bad caller/trailer Alt-Used controls prevent peer connection/body polling, and critical-hints replay requires exact first/second observations with no extra accepted connection. Clear/421 cases check subsequent behavior, not only exported state. Loopback IPv6 uses an owned shared-port helper and narrow platform-unavailable skip.

`http3.rs`: Ready data/head/trailer tests have literal expected body/fields with real gated peers. HeaderMap trailer assertions preserve values/sensitivity but do not alone prove cross-name interleaving; separately reviewed raw trailer controls cover that stronger claim. SOCKS cases observe actual association count, authority/path/DNS name and connection reuse; setup-error controls use typed causes plus no-origin observations. Quiet TCP/UDP windows and runtime-drop cleanup remain bounded fixture observations.
