## Concrete source findings

- Ordinary raw server handles cross fallible caller construction/send/body work
  (44-60, 77-137, 152-175, 374-434). A caller error or five-second outer expiry
  drops the raw handle without joining its original result. No permanent leak
  is established; client teardown may subsequently finish the worker.
- Independent-client coordinator spawns the first accepted H2 child at 202,
  then awaits another fallible TLS accept at 203. Later acquisition failure or
  coordinator cancellation drops the original first child result handle.
  The array at 205 also propagates the first error before observing the second.
- Tunnel origin starts before fallible proxy acquisition/configuration. The
  origin await/assertions at 263-269 and 323-329 can skip the original proxy
  result. Both actual relay implementations already propagate unrelated errors.
- Concurrent caller tasks at 159-172 and 210-214 have the same first-result
  propagation gap. They require their own request ownership slice.
- The invalid-header test has no spawned peer and needs no task owner repair.

## H2 lifetime constraints

Keep response-body collect/drop, upload release_capacity, stream IDs 1/3,
CANCEL observation, literal responses, route authority bytes, and all original
assertion order. Keep the original five-second test period. The abandoned-body
server must continue polling accept/poll_reset until both signals, then drop
stream handles before poll_closed. The upload collector and its two existing
controls are frozen; do not alter their stream-first/driver/re-poll ordering.

serve_requests sends replies then awaits poll_closed. Resolved server accept
and poll_closed drive reads and queued writes. Successful fixture joining must
follow body and Client teardown, as the original tests do. ConnectionLease holds
ConnectionInner; its Drop closes the final sender before DriverTask shutdown.
The original driver supervisor allows one second to flush protocol frames.
Do not add early GOAWAY, stop a required server before request/body/client
teardown, or change library driver behavior for test cleanup.

H2 protocol errors already convert I/O payloads to kind/text in
vendor/http2/src/proto/error.rs:94-96. H2 fault controls must preserve the
original resulting ::http2::Error with get_io kind/message; they must not demand
an Arc marker through that conversion. The direct relay can preserve an actual
io::Error payload by move. This dependency behavior is not a new fixture defect.

## Minimal staged ownership design

First expose canonical forwarding seams without changing raw policy. A concrete
reuse-server factory serves the existing serve_requests body; a concrete nested
coordinator function retains the existing first/second accept and child bodies.
Any stream adapter only instruments the original accepted stream, with identity
ordinary use. No copied server, replacement task, result proxy, shared helper
change, manifest change, or generic ownership framework.

After independent source review and paired causal baseline, use the existing
ConnectionPeer immediately for each original task, retaining owners outside the
caller deadline. A nested coordinator owns each child immediately, before the
next accept. On primary failure it requests cancellation only for observed
pending children, attempts each finite original join independently, and composes
original accept/caller/child results without early propagation. A ready original
error or foreign cancellation remains an error. Success keeps drivers active
until actual caller teardown, then joins without a premature abort.

Upload/reset workers have different concrete result types and can retain local
ConnectionPeer owners without forcing a common result enum. A later tunnel
slice uses explicit origin/proxy owners, including partial proxy acquisition,
and collects both original outcomes before returning either error. Preserve
plain relay error propagation and HTTPS relay's existing four-disconnect rule.
The shared ConnectionPeer::stop unconditionally accepts cancellation, so do not
use it to promise foreign cancellation preservation.

## Proposed first tests-only checkpoint

Owned files: sessions/session.rs and session/reuse_ownership.rs, with a nested
reuse_ownership/tests.rs if fixture size warrants it. No proxy_auth,
upload_contract, source_binding, runtime, shared support, or production edits.
Keep all eight original methods and existing deadline/upload/proxy controls.
Only necessary canonical forwarding wrappers change original caller source.

Five single-peer controls: literal healthy 204 with caller teardown and original
result; explicit original abort/join; completed real H2 I/O error observed
through its original result; live-runtime pending original owner Drop; real
Phantom caller error plus completed original server cause. Require actual
accepted TLS/H2 progress and original future destruction/completion before any
backup action. Forecast 3 pass / 2 fail under raw baseline, not measured.

Four nested controls: healthy two real independently built clients/stream 1 on
each; coordinator Drop while actual first H2 child is pending in poll_closed and
actual second TLS accept is pending; actual second TLS accept failure while
first child remains pending; actual second acquisition failure plus an already
completed original first-child H2 cause. The coordinator remains sole child
result owner; AbortHandles only witness/cancel that same task. Holding the first
Client alive prevents a normal teardown from hiding the negative. Separate
actual second-accept entry, first-driver Pending, child destruction, and socket
closure observations precede backup cancellation. Forecast 1 pass / 3 fail,
not measured. This gives nine controls, forecast 4 pass / 5 fail. Exact tests
must be independently source-gated before these forecasts become requirements.

Nested explicit abort is not a raw baseline positive: aborting only a raw
coordinator does not abort its raw descendant. Do not manufacture a positive
by transferring its result to a backup. Backup may cancel same-task handles
only after the target oracle, and cannot substitute for original result joins.

## Deferred required scope

CONNECT positives and explicit original-peer joins; both peers' pending Drop;
real caller plus completed origin/proxy causes; first origin error with completed

request-owner controls remain a separate slice (healthy/explicit abort, pending
